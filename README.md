## 📌 Project Overview
A fully responsive, semantic, modern single-page visual portal website built according to modern web development standards.

### ✨ Key Features
- **Semantic HTML5:** Built using semantic tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<blockquote>`, `<footer>`).
- **Custom CSS Grid & Flexbox:** Fluid layouts across all screen breakpoints without relying on heavy external CSS frameworks.
- **Interactive Mobile Navigation:** Animated hamburger-to-X menu with accessible focus trap and background backdrop blur.
- **IntersectionObserver Animations:** Dynamic scroll-reveal effects and smooth-filling animated skill progress bars.
- **Interactive Project Filtering:** Instant category filter (All, Web App, Mobile, Design) with fade animations.
- **Tabbed Experience Timeline:** Switch between Work Experience and Education (BS CS, FSc, Matric).
- **Client-Side Form Validation:** Real-time form checks with feedback and async simulation state.
- **Accessibility & Performance:** WCAG compliant with Skip-to-content links, ARIA labels, and `prefers-reduced-motion` support.

## 🛠️ Tech Stack
- **HTML5:** Semantic markup & accessible structure
